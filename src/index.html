JavaScript debugging

      
The Node Inspector can pause a JavaScript run and allow attachment from Chrome DevTools or a compatible debugger. This is not yet a full in-app Debug Adapter Protocol frontend.

      
Ready

      
Debugging requires Node.js to be available to the runner. The inspector binds to localhost and uses an ephemeral port; copy the WebSocket URL from Terminal / Output to attach a debugger. Only debug code you trust.

      
Plugin security center

      
Plugins run with the app user's operating-system permissions. Disable anything you do not trust. Permission declarations are informational, not a security sandbox.

Important: process isolation alone does not remove OS permissions. Strong isolation for untrusted plugins requires a dedicated OS sandbox or virtualization layer.
